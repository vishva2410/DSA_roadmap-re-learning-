# DSA Foundation Plan

A clean DSA roadmap for people who are tired of random sheets, endless tutorials, and solving problems without actually understanding anything.

This is a beginner-to-strong-foundation learning map with 120+ curated problems across the core DSA topics.

The goal is simple:

> Build enough problem-solving intuition that you can solve problems without depending on AI, editorials, or memorized patterns.

4. Searching
5. Sorting
6. Hashing
7. Recursion
8. Stack & Queue
9. Trees
10. Math & Bit Manipulation

---

## 3. Don't Rush Problems

The biggest mistake beginners make:

They watch the solution too fast.

Instead:

### Before coding:

* Read the problem
* Close everything
* Think for 15–30 mins
* Write the idea in English first
* Dry run manually

### After coding:

* Write the KEY INSIGHT in one sentence
* Revisit after a few days
* Solve again without notes

That's where actual learning happens.

---

# Recommended Pace

You do NOT need 8 hours/day.

Even:

* 2 problems/day
* consistently
* for 2 months

is enough to build a strong base.

Suggested timeline:

| Weeks | Topics                     |
| ----- | -------------------------- |
| 1–2   | Arrays + Strings           |
| 3–4   | Linked Lists + Recursion   |
| 5     | Sorting + Searching        |
| 6     | Hashing + Stack/Queue      |
| 7–8   | Trees + Math/Bits          |
| 9+    | Revision + Medium Problems |
