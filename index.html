Build concept memory from scratch — easy → medium. Arrays, Strings, Linked Lists + all core topics.

Problems: 120+
Topics: 10
Platforms: LC · GFG · CN · HackerRank
Goal: Solve without AI

// How to study each problem

01

Read → Close → Think. Don't look at hints. Spend 15–20 min on easy, 30 min on medium. Time yourself.

02

Write the approach in English first. "I'll use two pointers, starting at both ends, and move left if..." — this forces clarity before code.

03

Trace through a small example by hand. Draw the array. Move the pointers manually on paper. Don't trust your head.

04

Code it. Then write the KEY INSIGHT in one sentence in a personal notebook. That sentence is what you'll remember — not the code.

05

After finishing a topic, revisit all its problems after 3 days without looking at your notes. If you can't do it, redo. This is spaced repetition.

TOPIC 04 Searching — Linear & Binary Search 12 problems

Core Concepts to Build

What you're learning: Binary search template, boundary conditions (lo, hi, mid), searching in rotated arrays, first/last occurrence.

Algorithm patterns:

Binary search: lo=0 hi=n-1 Upper / lower bound Search on answer

Template: lo=0, hi=n-1. While lo≤hi: mid=lo+(hi-lo)/2. Decide: go left or go right. Never use lo+hi (overflow).
